About TopoScout

This tool helps you analyze terrain to find highest points, calculate maximum ascent, visualize slope steepness, and overlay GPX routes on the map. The app is designed to work on mobile devices as well.

GitHub Project / droidgren.github.io

Version: 2.25.3 (Build 3048)

Changelog
  • v2.25.3: Updated the map engine to MapLibre GL JS 6.5.0 — the point under the pointer is now read straight from the terrain data at full resolution, so elevation readings in 3D/tilt mode are more accurate and panning is smoother. Switching basemap no longer degrades the frame rate, and raster tiles no longer flash when they reload.
  • v2.25.2: Fixed two problems the browser was reporting in the background. The staged security policy did not allow the Google profile picture or the sign-in button's stylesheet, so promoting it would have broken sign-in. The POI colour picker's Color heading also named nothing to a screen reader, and the picker now says which colour is selected.
  • v2.25.1: Add Routes and POIs is now Create Routes and POIs, and it sits at the top of the control panel instead of the bottom. Drawing a route is a thing you do, not an afterthought to a terrain scan. The tutorial walks the sections in the new order, and the Swedish label reads Skapa spår och POI:er in both places (the panel said rutter, the tutorial said spår).
  • v2.25.0: Shared links now get a real preview card, and search engines see a title, description, canonical URL and structured data. Accessibility pass: every icon-only button has a name, the four panel sections became keyboard-reachable headings, and the page now declares the language it is showing. HTTPS is enforced and the device APIs the app never uses are switched off.
  • v2.24.0: The elevation box is now a single data box: elevation stays the big number, with Zoom and Scale as tiles beside it and distance-to-GPS and coordinates on a line below. Distance-to-GPS and coordinates now show by default. On phones it is a single compact line instead of a box.
